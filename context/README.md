# Project Context Index

Load in order:

1. `product.md` — scope, users, acceptance criteria, and non-goals.
2. `stack.md` — verified toolchain and package choices.
3. `architecture.md` — deployables, dependency direction, data flow, and invariants.
4. `ui.md` — dashboard UI, accessibility, and frontend boundary.
5. `security.md` — data classification, threat controls, and approval boundaries.
6. `workflows.md` — branches, quality gates, local runtime, and recovery.
7. `decisions.md` — accepted durable architecture decisions.

This directory is sanitized durable context. Secrets, raw provider payloads, local Supabase state, reports, logs, and task progress stay out of Git.
